# Моя коллекция игр

Android-приложение для коллекционеров консольных игр (сканер, каталог по платформам, оценка стоимости, обмен коллекциями).

## Как получить APK без Android Studio
1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки (включая скрытую папку `.github`).
2. Вкладка **Actions** → workflow **Build** → **Run workflow**. Готовый APK и пакеты платформ появятся в **Artifacts**.
3. Для релиза: Releases → Draft a new release → тег `v0.1.0` → Publish. Workflow соберёт APK и приложит его к релизу.

## Подпись APK
Без настройки APK подписывается временным debug-ключом, и **каждая новая сборка нельзя поставить поверх предыдущей** (нужно удалять старую). Чтобы обновления ставились поверх, создайте постоянный ключ и добавьте секреты репозитория: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.

## Пакеты платформ
`python3 tools/build_packs.py [ps1 n64 ...]` собирает SQLite-базы в `packs/` (данные Redump / No-Intro через libretro-database).
